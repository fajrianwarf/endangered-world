## Sumber informasi konservasi

Informasi mengenai status, habitat, persebaran, ancaman, dan upaya konservasi pada dataset menggunakan sumber yang dicantumkan di properti `source` setiap hewan. Sumber utama yang digunakan adalah:

- **World Wildlife Fund (WWF)** — halaman spesies untuk hewan yang memiliki referensi WWF khusus.
- **IUCN Red List of Threatened Species** — digunakan sebagai referensi konservasi untuk sejumlah spesies yang pada dataset saat ini mengarah ke portal IUCN.

## Sumber gambar

Seluruh gambar hewan pada dataset terbaru menggunakan halaman file dari **Wikimedia Commons**. Properti `image` pada `animals.json` menggunakan URL `Special:Redirect/file/...` agar browser langsung memuat berkas gambar, sedangkan `imageSourcePage` menyimpan halaman atribusi asli.

Jika gambar tidak dapat dimuat, website menggunakan fallback lokal:

- `assets/image-error.svg` — placeholder internal Endangered World.

## Sumber video dan audio

Video menggunakan berkas media dari **Wikimedia Commons**, terutama format WebM. Pada dataset, `video.sourcePage` menyimpan halaman file asli untuk atribusi.

Untuk hewan yang memakai file media yang sama sebagai sumber suara, `audio.url` menunjuk ke file WebM yang sama dengan video. Audio yang terdengar berasal dari audio track yang terdapat di dalam berkas tersebut; bukan rekaman audio terpisah.

## Logo

Logo Endangered World menggunakan aset yang diberikan secara langsung untuk proyek ini dan disimpan sebagai:

- `assets/logo.png`

Logo tersebut bukan diambil dari sumber eksternal yang tercantum pada dokumen ini.

## Catatan lisensi

Wikimedia Commons menampung media dengan berbagai lisensi. Karena lisensi dapat berbeda untuk setiap file, jangan menganggap seluruh media menggunakan lisensi yang sama. Sebelum publikasi atau distribusi ulang, buka halaman sumber masing-masing file dan ikuti:

1. nama kreator/pemilik hak;
2. jenis lisensi;
3. format atribusi yang diwajibkan;
4. ketentuan share-alike atau perubahan karya, jika ada.

Field `imageCredit`, `imageLicense`, `video.credit`, `video.license`, `audio.credit`, dan `audio.license` di `animals.json` berfungsi sebagai metadata pendukung, tetapi **halaman sumber asli tetap menjadi rujukan utama untuk lisensi**.
